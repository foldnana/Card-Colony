# 河湾市场交易系统实现说明 v0.2

## 版本目标

本版本验证三个核心功能：

1. 购买基础物资。
2. 出售玩家物品。
3. 每日刷新少量商品库存。

市场不承担武器装备、住宿或恢复服务。武器装备留给铁匠铺，住宿和恢复留给旅馆。

## 市场布局

- 下方：入口和玩家出生位置。
- 左侧：苹果、浆果、土豆和生肉四个食物摊。
- 右侧：木材、石头和绳子三个材料与旅行用品摊。
- 中间：杂货商 NPC。
- 上方：收购柜台。
- 右下方偏内侧：购买后商品出现的取货台，避开右侧信息面板。

## 商品与每日库存

| 商品 | 买价 | 每日库存 |
| --- | ---: | ---: |
| 浆果 | 2 金币 | 3～5 |
| 苹果 | 3 金币 | 2～4 |
| 土豆 | 3 金币 | 2～4 |
| 生肉 | 5 金币 | 1～3 |
| 木材 | 2 金币 | 2～4 |
| 石头 | 2 金币 | 2～4 |
| 绳子 | 5 金币 | 1～3 |

每日库存会写入市场地点的存档数据。同一天离开并重新进入市场不会补满库存，进入下一天时才会刷新。

## 购买流程

1. 点击商品摊位。
2. 右侧地点面板切换为“商品”，显示商品类型、价格和今日库存。
3. 点击“购买”。
4. 系统优先扣除背包中的散装金币，不足部分再从当前桌面扣除。
5. 商品卡出现在右下角取货台旁边。
6. 库存减一，售罄后按钮不可用。

不再支持把金币拖到商品卡上直接购买。

## 出售流程

1. 从桌面或背包拖出可出售物品。
2. 把物品放到上方收购柜台。
3. 右侧面板显示待售数量和出售总价。
4. 点击“确认出售”。
5. 物品消失，金币作为同一卡堆一次性写入背包。

在确认前点击其他卡牌、拿起待售物，或再次点击收购台关闭详情，都会取消待售状态，物品不会消失。

连续放到收购台的物品会像普通卡牌一样合并为一个待售卡堆，并排列在柜台左侧，不与中央杂货商重叠。出售成功时背包只刷新一次，避免逐枚加入金币造成显示重建异常。

收购范围为具有正数售价的食物、材料、装备和贵重物品；不收购角色、建筑、地点静态卡和货币。

## 技术结构

- `LocationDefinition`：独立配置市场货币、收购台、取货台、商品、价格和库存上下限，不覆盖其他地点原有交易货币。
- `MarketStockLedger`：保存商品当日剩余库存，并在日期变化时刷新。
- `MarketCurrencyService`：统一统计和扣除背包及桌面上的散装金币。
- `MarketProductVendor`：处理商品卡选中、库存展示和点击购买。
- `MarketCardBuyer`：处理待售物品的正常堆叠、价格预览和确认出售。
- `WorldMapLocationView`：复用现有右侧地点面板显示市场商品和收购信息。
- `RiverbendMarketInstaller`：可重复生成市场地点、七个摊位、取货台及场景配置。

## 暂不实现

- 购买数量选择和批量购买
- 找零、自动拆分非金币卡堆
- 商人好感、折扣和动态价格
- 跨市场共享库存
- 火把、药水等旅行用品
- 武器装备与旅馆服务
