# NPC 人物卡通用交易改造小策划 v0.2

> 编制日期：2026-07-27  
> 改造范围：人物 NPC 通用交易入口与河湾市场迁移  
> 本期目标：取消商品摊位卡和独立收购台，让理论上任何非敌对人物 NPC 都能交易；不同 NPC 通过职业、个人库存、收购偏好、资金和关系条件决定可以买卖什么。  
> 非本期内容：动态价格、跨地区跑商、合同、商人好感、批量货物和市场事件。

## 1. 改造目的

当前河湾市场使用七张商品摊位卡和一张收购台卡：

- 每种商品占用一张摊位卡。
- 购买需要逐个点击摊位。
- 出售需要把商品拖到独立收购台。
- 商人 NPC 与实际交易功能分离。

商品继续增加后，市场桌面会越来越拥挤，商人也缺少存在感。

本次改造后：

- 市场不再为每种商品生成一张摊位卡。
- 所有非敌对人物 NPC 都具备通用交易入口。
- 玩家选中人物后，在右侧状态栏查看其购买、出售和交谈内容。
- 每个 NPC 出售的商品、愿意收购的商品、资金和价格修正可以不同。
- 商人、铁匠、药师、旅店老板、村长和普通居民复用同一套交易系统。
- NPC 的对话和交易由同一张人物卡承载。

## 2. 场景调整

### 2.1 移除内容

从河湾市场初始卡牌中移除：

- 苹果摊。
- 浆果摊。
- 土豆摊。
- 生肉摊。
- 木材摊。
- 石头摊。
- 绳子摊。
- 独立收购台。

对应摊位可以继续画在市场背景中，但不再作为可选中卡牌存在。

### 2.2 保留内容

- 河湾市场背景。
- 杂货商人物卡。
- 玩家进入市场的位置。
- 取货区的视觉位置。

取货区不再作为可选服务卡。首版购买成功后，商品仍可以在原取货区附近生成，保留“购买后拿到实体卡”的反馈。

## 3. 核心交互

### 3.1 打开人物状态栏

玩家点击任意非敌对人物 NPC 卡：

1. 人物卡高亮。
2. 右侧状态栏打开。
3. 状态栏显示人物头像、名称、职业和简介。
4. 如果该人物有出售商品，默认进入“购买”页签。
5. 如果该人物没有出售商品但愿意收购物品，默认进入“出售”页签。
6. 如果双方当前不能交易，默认进入“交谈”页签，并显示不能交易的原因。

再次点击该人物或点击其他卡牌，关闭人物状态。

### 3.2 右侧状态栏

右侧状态栏提供三个页签：

| 页签 | 内容 |
| --- | --- |
| 购买 | 当前 NPC 愿意出售的商品、价格和库存 |
| 出售 | 玩家持有且当前 NPC 愿意收购的商品 |
| 交谈 | 打开该 NPC 的基础对话 |

本期不加入合同和好感页签，但界面结构应允许后续增加。

页签根据人物能力动态显示：

- 有出售内容时显示“购买”。
- 有收购规则时显示“出售”。
- 可以对话时显示“交谈”。
- 某个页签暂时无内容时可以保留并显示“今天没有可交易内容”，不得产生空白面板。

### 3.3 购买流程

“购买”列表每行显示：

- 商品图标。
- 商品名称。
- 单件价格。
- 今日剩余库存。
- 购买按钮。

流程：

1. 玩家点击人物 NPC。
2. 在“购买”页签选择商品。
3. 点击“购买”。
4. 系统检查金币和库存。
5. 扣除金币。
6. 商品卡在取货区附近生成。
7. 对应商品库存减一。
8. 状态栏立即刷新金币和库存。

首版继续采用一次购买一件，不在本次改造中增加数量选择。

### 3.4 出售流程

“出售”列表只显示：

- 玩家当前持有的卡牌。
- 符合当前 NPC 收购类别或指定清单的卡牌。
- 售价大于零的卡牌。
- 不在战斗、装备或其他锁定状态中的卡牌。

列表每行显示：

- 商品图标。
- 商品名称。
- 持有数量。
- 单件售价。
- 本次出售总价。
- 选择按钮。

流程：

1. 玩家切换到“出售”页签。
2. 选择一类商品。
3. 选择出售一件或出售该类全部。
4. 状态栏显示出售预览。
5. 玩家点击“确认出售”。
6. 商品从背包或当前市场桌面移除。
7. 金币进入背包。
8. 状态栏立即刷新持有数量和金币。

出售必须经过确认，选择商品时不能直接删除卡牌。

## 4. 点击与拖拽规则

为避免交易和对话冲突，统一使用以下规则：

| 操作 | 结果 |
| --- | --- |
| 点击任意非敌对人物 NPC 卡 | 打开右侧人物状态栏，并显示其可用交易页签 |
| 玩家角色卡拖到 NPC 卡 | 打开人物对话 |
| 商品卡拖到 NPC 卡且对方愿意收购 | 打开该商品的出售预览 |
| 商品卡拖到 NPC 卡但对方不收购 | 商品返回原位并显示拒绝原因 |
| 点击其他普通卡牌 | 关闭当前人物交易状态 |
| NPC 处于对话、战斗或任务锁定状态 | 暂时禁止交易并显示原因 |

商品拖到 NPC 卡上时不得立即出售，只能定位到“出售”页签并等待确认。

## 5. NPC 通用交易配置

### 5.1 `NpcTradeProfile`

所有人物 NPC 都通过同一种 `NpcTradeProfile` 描述交易能力，不再区分“能交易的商人组件”和“完全不能交易的普通 NPC”。

| 字段 | 用途 |
| --- | --- |
| `tradeProfileId` | NPC 交易配置 ID |
| `npcDefinition` | 对应人物卡 |
| `roleTemplate` | 杂货商、铁匠、药师、旅店老板、普通居民等模板 |
| `currencyDefinition` | 使用的货币 |
| `sellOffers` | NPC 主动出售的商品 |
| `buyCategories` | NPC 愿意收购的卡牌类别 |
| `buyDefinitions` | 指定收购商品及价格修正 |
| `rejectedDefinitions` | 明确拒绝收购的商品 |
| `startingFunds` | NPC 初始可用资金 |
| `maximumFunds` | NPC 资金上限 |
| `refreshDays` | 个人库存刷新周期 |
| `buyPriceModifier` | NPC 收购价格修正 |
| `sellPriceModifier` | NPC 出售价格修正 |
| `allowSellFromBackpack` | 是否读取背包商品 |
| `allowSellFromTable` | 是否读取当前桌面商品 |
| `relationRequirement` | 可选的关系门槛 |
| `questRequirement` | 可选的任务条件 |
| `refusalText` | 不收购时的提示 |

单个 `NpcSellOffer` 暂时沿用当前市场字段：

- 商品定义。
- 固定买价。
- 每日最小库存。
- 每日最大库存。
- 可选关系或任务解锁条件。

本期不修改现有价格模型和库存刷新规则，只把价格与库存配置从摊位迁移到人物。

### 5.2 默认交易能力

为了实现“理论上任何人物 NPC 都可以交易”，系统按以下优先级解析配置：

1. NPC 自己的显式 `NpcTradeProfile`。
2. NPC 职业对应的 `NpcTradeRoleTemplate`。
3. 全局“普通居民”默认模板。

普通居民默认模板：

- 偶尔出售 0～2 件个人物品或本地生活物资。
- 收购少量食物、药品和普通日用品。
- 资金很少，不能承担大宗交易。
- 不收购任务物品、货币、地点卡、人物卡和静态设施。
- 个人库存 2～4 天刷新一次。

这样即使某个 NPC 没有单独配置，右侧状态栏仍然可以显示其个人交易内容，而不是直接失去交易能力。

### 5.3 NPC 类型示例

| NPC | 可以卖给玩家 | 愿意从玩家处购买 | 交易特点 |
| --- | --- | --- | --- |
| 杂货商 | 食物、木材、绳索 | 食物、材料、日用品 | 品类多、资金较多 |
| 铁匠 | 工具、武器、护甲 | 矿石、金属、旧装备 | 专业品类、高价物 |
| 药师 | 药品、草药制品 | 草药、蘑菇、药材 | 医疗品价格较好 |
| 旅店老板 | 食物、饮料、旅行补给 | 食材、燃料 | 少量稳定需求 |
| 村长 | 地图、许可证、任务物品 | 指定委托物 | 主要受任务条件控制 |
| 普通居民 | 少量个人物品 | 食物、药品、生活品 | 随机少量、资金有限 |

“任何 NPC 可以交易”不等于“任何 NPC 什么都收”。人物身份和需求决定交易差异。

### 5.4 NPC 个人交易状态

新增 `NpcTradeState` 并写入地点存档：

| 字段 | 用途 |
| --- | --- |
| `npcId` | NPC ID |
| `availableFunds` | 当前剩余资金 |
| `remainingStock` | 当前出售库存 |
| `acquiredItems` | 玩家卖给该 NPC 的个人物品 |
| `lastRefreshDay` | 上次刷新日期 |
| `stateVersion` | 存档版本 |

普通 NPC 的库存和资金必须保存。重复点击、离开地点再返回或读档，都不能立即刷新个人商品和金币。

玩家卖给普通 NPC 的商品可以进入其 `acquiredItems`，之后允许以更高的出售价格买回；专业商人可以选择把收购品并入自己的常规库存。

### 5.5 本期价格规则

本期暂不实现地区动态价格，使用可配置固定价格：

```text
NPC 出售价 = 商品配置买价 × NPC 出售修正
NPC 收购价 = 卡牌基础售价 × NPC 收购修正
```

约束：

- 同一个 NPC 的出售价必须高于收购价。
- NPC 收购修正建议为 0.8～1.2。
- 专业 NPC 对对应材料可以给出较高收购价。
- 普通居民资金少，不能成为无限物品回收站。
- 任务物品和特殊交换物必须显式配置，不能套用普通售价。

## 6. 程序职责调整

### 6.1 新增 `NpcTrader`

由地点人物初始化流程挂载到所有非敌对人物 NPC，负责：

- 处理人物卡选中。
- 读取 NPC 显式配置、职业模板或普通居民默认模板。
- 通知右侧状态栏打开或关闭。
- 提供购买列表和出售列表。
- 调用现有金币、库存与出售规则。
- 在对话、战斗或任务锁定期间暂停交易。

### 6.2 改造右侧状态栏

现有地点状态栏增加通用 NPC 模式：

- `SelectedNpc`
- `ShowNpc`
- `ShowNpcBuyList`
- `ShowNpcSellList`
- `RefreshNpcView`

状态栏不自行修改金币或销毁卡牌，只负责展示和提交玩家选择。

### 6.3 新增 `NpcTradeService`

统一负责：

- 判断 NPC 当前是否允许交易。
- 合并显式配置、职业模板和默认模板。
- 根据 NPC 收购规则过滤玩家物品。
- 校验 NPC 库存、资金和玩家金币。
- 执行购买、出售和买回交易。
- 更新 `NpcTradeState`。
- 返回明确的拒绝原因。

`NpcTrader` 和右侧状态栏都不能直接删除卡牌或生成金币。

### 6.4 复用现有功能

继续复用：

- `MarketCurrencyService`
- `MarketStockLedger`
- `MarketTradeRules`
- 当前购买后的商品生成逻辑
- 当前出售确认后的金币发放逻辑

旧组件处理：

- `MarketProductVendor` 不再挂到七张摊位卡。
- `MarketCardBuyer` 不再挂到独立收购台。
- 其实际购买和出售逻辑迁移到 `NpcTradeService`。

### 6.5 NPC 交易配置解析

新增 `NpcTradeProfileResolver`：

```text
Resolve(NPC)
    → 查找 NPC 专属配置
    → 没有则查找职业模板
    → 没有则使用普通居民模板
    → 合并关系和任务条件
    → 返回本次可用交易能力
```

`LocationSceneController` 在地点人物生成完成后：

1. 找出非敌对人物卡。
2. 为其添加或取得 `NpcTrader`。
3. 通过 `NpcTradeProfileResolver` 解析交易配置。
4. 从地点存档加载对应 `NpcTradeState`。
5. 绑定人物选择事件和右侧状态栏。

敌人、地点、建筑、资源和动物不进入这套 NPC 通用交易流程。

## 8. 存档与兼容

- 保留现有商品每日库存数据。
- 原七个摊位对应的库存 ID 继续使用，避免旧存档库存被重置。
- 摊位卡从地点生成列表移除后，不再保存它们的位置。
- 杂货商成为新的交易入口，但不改变其原人物卡 ID。
- 河湾村现有村长、铁匠、杂货商和药师均获得稳定的 `NpcTradeState`。
- 未显式配置交易的其他人物 NPC 使用普通居民模板初始化个人库存和资金。
- 每个 NPC 的交易状态按 NPC ID 保存，不能只按职业或卡牌类型保存。
- 旧存档进入市场时，自动清理仍然存在的摊位卡和收购台卡。
- 清理过程不得影响玩家已经购买的普通商品卡。
- 旧存档第一次生成 NPC 个人交易状态后立即保存，重复读档不能重抽库存。

## 9. 本期验收标准

- [ ] 河湾市场不再生成七张商品摊位卡。
- [ ] 河湾市场不再生成独立收购台卡。
- [ ] 所有非敌对人物 NPC 卡保持不可随意拖走。
- [ ] 点击任意非敌对人物 NPC 都会打开右侧人物状态栏。
- [ ] 每个 NPC 根据自身配置显示不同的购买和出售列表。
- [ ] 未显式配置的 NPC 会使用普通居民交易模板。
- [ ] 杂货商购买页签显示七种现有商品、价格和库存。
- [ ] 玩家可以从列表购买商品。
- [ ] 出售页签只显示杂货商愿意收购的玩家物品。
- [ ] 铁匠、药师、村长和普通居民不会显示完全相同的收购范围。
- [ ] 玩家可以出售一件或出售同类全部。
- [ ] 出售前必须显示价格并再次确认。
- [ ] 玩家角色卡拖到任意可对话 NPC 仍能触发对话。
- [ ] 商品卡拖到愿意收购它的 NPC 时只打开出售预览，不会立即消失。
- [ ] 商品卡拖到不收购它的 NPC 时返回原位并显示拒绝原因。
- [ ] NPC 的库存和资金在重新进入地点后保持正确。
- [ ] 当日库存、金币和已购物品在重新进入市场后保持正确。
- [ ] 旧存档中的摊位卡和收购台能够安全清理。
- [ ] 原有市场专项测试更新后全部通过。

## 10. 建议实现顺序

### 第一步：通用数据

- 新增 `NpcTradeProfile`。
- 新增 `NpcTradeRoleTemplate`。
- 新增 `NpcTradeState`。
- 新增杂货商、铁匠、药师、旅店老板、任务人物和普通居民模板。

完成标准：不进入场景也能解析任意 NPC 的出售清单、收购清单和资金。

### 第二步：通用人物交易组件

- 新增 `NpcTrader`。
- 新增 `NpcTradeProfileResolver`。
- 让地点初始化流程为全部非敌对人物 NPC 配置交易能力。
- 对话、战斗和任务锁定状态可以临时禁用交易。

完成标准：点击任意河湾村人物都能得到明确的交易能力或拒绝原因。

### 第三步：右侧人物状态栏

- 把当前市场商品详情改造成购买列表。
- 新增出售列表和出售预览。
- 根据 NPC 能力动态显示购买、出售和交谈页签。
- 切换人物时清理上一个人物的待确认交易。

完成标准：杂货商、铁匠和药师显示不同的列表，且列表不会串到另一个 NPC。

### 第四步：统一结算

- 新增 `NpcTradeService`。
- 迁移现有购买、出售、金币和库存逻辑。
- 交易成功后同时更新玩家物品、NPC 库存和 NPC 资金。
- 任一步骤失败时不改变双方状态。

完成标准：金币不足、库存不足、NPC 资金不足和物品被锁定时都不能产生半笔交易。

### 第五步：河湾市场迁移

- 删除七张摊位卡和独立收购台卡。
- 把七种现有商品迁移到杂货商配置。
- 保留旧库存 ID 和取货位置。
- 为旧存档增加一次性清理和 NPC 交易状态初始化。

## 11. 本期完成后的效果

改造完成后，河湾市场不再需要商品摊位卡。玩家可以和任何非敌对人物 NPC 打交道：

```text
点击任意人物 NPC
    → 读取 NPC 自身配置 / 职业模板 / 普通居民模板
    → 右侧显示这个人物自己的购买列表
    → 切换出售列表
    → 选择商品
    → 预览价格
    → 确认交易
```

杂货商提供稳定日用品，铁匠收购矿石和旧装备，药师收购草药，普通居民只进行少量个人交易。玩家会感觉自己是在和具体人物做生意，而不是操作一组功能摊位。

后续增加 NPC 或商品时，只需要配置人物职业模板或个人交易规则，不再增加新的场景交易卡牌，也不需要为每种 NPC 编写独立交易代码。
